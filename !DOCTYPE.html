❓ SYSTEM USER MANUAL & PHYSICAL SKILL GUIDE
1. システム概要・コンセプト
『俺だけレベルアップな件』のシステム界面をモチーフにした自己成長管理アプリです。タスク選択、スケジュール、マップ、ポモドーロタイマー等を駆使してハンターランクを上げましょう。
2. 各スキルポイント（物理パラメータ含む）を上げるやり方
ハンターの肉体と知性を極限まで高めるため、各ステータス（STR / INT / AGI / SEN / VIT）を効率的に上げるための具体的な実践方法を伝授します。
  • 💪 STR（筋力）を上げるやり方: パイクプッシュアップやディップス、ジムでの高重量ウェイトトレーニングを実践。朝・昼・晩に分けて負荷を分散させることで、効率よく筋繊維を刺激してSTRを爆発的に高めよ。
  • 📚 INT（知力）を上げるやり方: 英単語の暗記や資格の勉強、プログラミング学習などをタスクに登録。右パネルの「FOCUS TIMER（ポモドーロ）」を起動して完全没入し、セッション完了時の「INT+1 / +15 EXP」ボーナスを獲得せよ。
  • ⚡ AGI（敏捷：物理スピード・反射神経）を上げるやり方: ダッシュ、短距離走、スポーツにおける俊敏な身のこなし、ラダートレーニングや反射神経を鍛える運動をクエストに設定せよ。身体のキレ、走るスピード、瞬発的な反応速度を直接鍛えることで、物理的なAGIポイントが大きく上昇する。
  • ✨ SEN（感覚）を上げるやり方: プログラミングの個人開発、デザイン制作、楽器演奏、プレゼン資料の美的構築といったクリエイティブ作業を実践せよ。タイマーで制限時間を設け、研ぎ澄まされた集中状態で完遂することでSENポイントが急上昇する。
  • 🧊 VIT（体力・メンタル）を上げるやり方: ドローイング（体幹トレーニング）や良質な睡眠、メンタルを整えるルーティンをDAILYに設定せよ。また、怠惰度（LZS）が溜まったらSHOPの「高級体力回復ポーション」で適宜浄化し、継続できる肉体と精神のバッファを維持せよ。
